# LingoQuest · 英语探险岛

一个可以直接玩的英语闯关网页原型。玩家选择喜欢的场景，完成理解、拼句和自主表达三个短任务，收集星星并继续探索；之后在回忆营地重新使用旧句子。

## 启动

需要 Node.js 20 或更新版本，无需安装依赖。

```bash
cd lingoquest-english-adventure
npm run dev
```

在浏览器打开 <http://127.0.0.1:4173>。开发服务器只监听本机。自定义端口可运行 `npm run dev -- --port 4174`。

## 可以体验的功能

- 六个场景世界、十八关、五十四个任务：日常相遇、生活小镇、旅行港湾、兴趣星球、学习工坊、职场城市。
- 三种可随时切换的常规体验：轻松探索、兴趣冒险、生活实用。先专注课程和整体样式，大字模式留待后续。
- 三种英语起点，与年龄和偏好独立设置；有基础的玩家可从每个区域的第二或第三关开始。
- 每关有理解选句、可撤回的词块拼句和换情境表达。重复单词分别保留，避免同词只能选择一次。
- 支持输入后对照，也可以先自己说一句再自查。英文对话、每个选项和中文题目可点按钮朗读，语音由浏览器提供。
- 提示、参考句和收起参考三个动作分开。未列出的自然表达可以自行对照；首次独立表达后确认同义，会保留自主回忆记录。
- 每关提供具体学习目标、关键句型和二至三个口袋词卡。独立表达后，角色会用英文和中文回应实际任务结果；通关后可在表达手册听和练习。
- 通关记录、最好星数、学习偏好保存在当前浏览器。复习按一、三、七、十四天安排，同一上海日重复练习不会刷高复习次数。

## 原型范围

目前是十八关的入门体验，用于验证玩法和常规交互。自主表达使用有限参考表达加自查，不提供语义理解模型、录音判分或发音评分；没有账户、多人存档和云同步。跨年龄适用性还需要真实使用者测试，具体设计见 [PRODUCT.md](./PRODUCT.md)。

## 验证

```bash
npm test
```

状态与内容测试覆盖存档恢复、独立区域解锁、重玩保留最好成绩、上海跨日复习、输入容错及全部关卡的词块和参考表达一致性。

`app.js` 负责界面和交互，`state.js` 负责进度与复习规则，`lessons.js` 负责课程数据，`styles.css` 和 `assets/` 负责视觉。

## GitHub Pages

```bash
npm run build
```

构建会把网站需要的公开文件写入 `_site/`，用于静态托管；本地服务器、文档、测试和试玩截图不会进入网站部署包。

`.github/workflows/pages.yml` 会在推送 `main` 后运行测试、构建并部署 GitHub Pages，也可以在 GitHub Actions 中手动触发。首次使用时，在仓库的 **Settings → Pages** 中把部署来源设为 **GitHub Actions**。

线上与本地使用不同的浏览器存储，原有本地进度不会自动迁移。所有页面资源均为相对路径，可部署在 GitHub Pages 的仓库子路径下。
